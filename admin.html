เพิ่มรูปภาพ ย่อขนาดรูป จัดเรียงลำดับ และลบรูปภาพเมนูได้ทันที บันทึกข้อมูลลงในเบราว์เซอร์อัตโนมัติ โดยไม่ต้องสร้างหรือใส่รหัส GitHub Token ใดๆ ทั้งสิ้น
🎉
ใช้งานได้ทันทีโดยไม่ต้องตั้งค่า Token: คุณสามารถเลือกไฟล์รูปเมนูจากเครื่องหรือมือถือ รูปภาพจะถูกบันทึกและแสดงที่หน้าเมนูลูกค้าทันที!

✨ ทดสอบระบบอย่างรวดเร็ว (Quick Test)

หากยังไม่มีไฟล์รูปเมนู กดปุ่มด้านขวาเพื่อสร้างรูปภาพเมนูตัวอย่าง 3 หน้าได้ทันที

1. อัปโหลดรูปภาพเมนู / Upload Menu Images

เลือกไฟล์รูปภาพจากมือถือหรือคอมพิวเตอร์ ระบบจะย่อขนาดให้อัตโนมัติเพื่อให้โหลดไว

📷
คลิกเพื่อเลือกรูปภาพ หรือลากไฟล์มาวางที่นี่
รองรับ JPG, PNG, WebP (เลือกหลายรูปพร้อมกันได้)

2. จัดการและเรียงลำดับหน้าเมนู / Manage & Reorder

กดปุ่ม ▲ เลื่อนขึ้น หรือ ▼ เลื่อนลง (หรือลากปุ่ม ⋮⋮) เพื่อจัดเรียงลำดับหน้าเมนู

3. ส่งออกข้อมูลสำหรับ GitHub Pages (ฟรีและไม่ต้องใช้ Token)

วิธีนำรูปและเมนูไปใส่ใน GitHub แบบง่ายๆ เพียงแค่ลากไฟล์วางบนเว็บ GitHub

★ วิธีที่ 1 (ง่ายที่สุดและแนะนำ): ดาวน์โหลด menu.json ไฟล์เดียวจบ

ดาวน์โหลดไฟล์ menu.json ที่มีรูปภาพของคุณรวมอยู่ข้างในเรียบร้อย จากนั้นนำไฟล์นี้เพียงไฟล์เดียวไปอัปโหลดทับที่หน้าแรกของ GitHub Repository เมนูอาหารของคุณจะแสดงผลบนมือถือของลูกค้าได้ทันที 100%!

2 วิธีที่ 2: บันทึกแยกไฟล์รูปภาพลงโฟลเดอร์ menu/

หากคุณต้องการเก็บไฟล์รูปภาพแยกไว้ในโฟลเดอร์ menu/ บน GitHub:

3 วิธีนำไฟล์ขึ้น GitHub Pages (ไม่ต้องใช้ Token)
  1. เปิดหน้า Repository ของคุณในเว็บไซต์ GitHub.com
  2. กดปุ่ม Add file → เลือก Upload files
  3. ลากไฟล์ menu.json ที่เพิ่งดาวน์โหลดมาวางลงในหน้าเว็บ GitHub
  4. กดปุ่มสีเขียว Commit changes
  5. รอประมาณ 1-2 นาที เมื่อรีเฟรชหน้าเว็บลูกค้า รูปเมนูจะแสดงขึ้นมาทันที!
