# 🍽️ เว็บเมนูร้านอาหารออนไลน์ (Static Restaurant Menu) - ไม่ต้องใช้ Token

เว็บเมนูอาหารออนไลน์แบบ Static 100% เขียนด้วย HTML, CSS และ JavaScript ล้วน 
**ไม่ต้องใช้ Backend, ไม่ต้องมีฐานข้อมูล, ไม่ต้องใช้ API Key และไม่ต้องใช้ GitHub Token ใดๆ ทั้งสิ้น!**

เปิดใช้งานฟรีตลอดชีพผ่าน **GitHub Pages** รองรับการเปิดบนมือถือจากแอป LINE หรือสแกน QR Code หน้าโต๊ะอาหาร โหลดเร็ว ไม่กระตุก พร้อมระบบแตะขยายภาพเต็มจอและซูมเข้าออก (Pinch-to-zoom)

---

## 📁 โครงสร้างไฟล์ในโปรเจกต์ (Files Structure)

```text
├── index.html        # หน้าเมนูหลักสำหรับลูกค้า (เปิดดูเมนู แตะซูมรูปภาพ)
├── admin.html        # หน้าระบบจัดการรูปภาพเมนู (เพิ่มรูป, ย่อรูป, สลับลำดับ, ลบรูป)
├── menu.json         # ไฟล์เก็บรายการและลำดับรูปเมนู: {"images": []}
├── .nojekyll         # ไฟล์ว่างสำหรับบอกให้ GitHub Pages ไม่ประมวลผล Jekyll
├── menu/
│   └── .gitkeep      # โฟลเดอร์สำหรับเก็บไฟล์รูปภาพเมนู
└── README.md         # คู่มือการติดตั้งและการใช้งาน
```

## 🚀 วิธีใช้งานและอัปโหลดเมนู (ง่ายมากใน 3 ขั้นตอน)

### 1. ใช้งานในหน้า Admin (`admin.html`)
- เปิดไฟล์ `admin.html` ในเบราว์เซอร์
- ลากหรือเลือกรูปภาพเมนูของคุณจากมือถือหรือคอมพิวเตอร์
- ระบบจะทำการย่อขนาดรูปให้พอดีและบันทึกภาพลงในระบบให้ทันที
- ใช้ปุ่ม **▲ เลื่อนขึ้น** หรือ **▼ เลื่อนลง** เพื่อสลับลำดับหน้าเมนู
- กดปุ่ม **"💾 บันทึกลำดับ / Save Order"**
- กดลิงก์ **"⬅️ ดูหน้าเมนูลูกค้า"** เพื่อดูหน้าเมนูที่ลูกค้าจะเห็นได้ทันที

---

### 2. วิธีนำขึ้น GitHub Pages เพื่อเปิดให้ลูกค้าดูฟรี (ไม่ต้องใช้ Token)

1. เข้าเว็บไซต์ [GitHub.com](https://github.com/) และสร้าง Repository ใหม่ (ตั้งค่าเป็น **Public**)
2. อัปโหลดไฟล์ทั้งหมด (`index.html`, `admin.html`, `menu.json`, `.nojekyll`, และโฟลเดอร์ `menu/`)
3. ไปที่แท็บ **Settings** → เมนูด้านซ้ายเลือก **Pages**
4. ตรงหัวข้อ **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **`main`** และโฟลเดอร์ **`/(root)`**
   - กดปุ่ม **Save**
5. รอประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์ของร้าน เช่น:
   `https://<ชื่อผู้ใช้>.github.io/<ชื่อคลัง>/`
6. นำลิงก์นี้ไปสร้างเป็น QR Code ติดไว้ที่โต๊ะอาหาร หรือส่งให้ลูกค้าใน LINE ได้เลยครับ!
